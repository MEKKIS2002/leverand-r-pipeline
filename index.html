Automatiser leverandørkommunikasjon

Send forespørsler om pris og leveringstid automatisk

Last opp ordre-filen (CSV/Excel eksportert fra Numbers). Appen finner automatisk hvilke leverandører du har spørsmål til og sender e-poster via Make.com. Kolonnene Brand og Product name leses automatisk.

1

Eksporter fra Numbers

File → Export To → CSV. Last opp filen i sidepanelet til venstre.

2

Konfigurer webhook

Lim inn Make.com webhook-URL i sidepanelet. Se tutorial nedenfor.

3

Skann og forhåndsvis

Klikk Skann, forhåndsvis e-postene og godkjenn per rad.

4

Make.com sender

Webhook trigges og Gmail/SMTP sender riktig e-post til leverandøren.

▸ Make.com Tutorial — Slik setter du opp webhook og Gmail-scenario
Del 1 — Opprett webhook i Make.com
  1. 1Logg inn på make.com og klikk + Create a new scenario
  2. 2Klikk den store +-sirkelen. Søk Webhooks → velg Custom webhook
  3. 3Klikk Add → navngi webhook «Leverandør Pipeline» → Save
  4. 4Kopier URL-en og lim den inn i «Webhook URL»-feltet i sidepanelet til venstre
  5. 5Klikk OK. Make.com venter nå på en test-request. Send én e-post fra denne appen for å lære Make.com datastrukturen
Del 2 — Koble til Gmail / SMTP
  1. 6Klikk + etter webhook-modulen. Søk Gmail → velg Send an Email
  2. 7To: klikk feltet og velg {{to}} fra webhook-dataene
  3. 8Subject: velg {{subject}}
  4. 9Content: velg {{body}} — dette er e-postteksten generert av appen
  5. 10Klikk Save → Run once for å teste → Aktiver scenariot med toggle ON
